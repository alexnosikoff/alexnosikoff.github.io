# dyadya.jo

Статический сайт-блог. Статьи пишутся в Markdown, сборка делается скриптом `build.mjs`, публикация через GitHub Pages.

## Как опубликовать статью
1. Создайте файл в `content/posts/название.md`.
2. В начале файла укажите:
   ```
   ---
   title: "Заголовок"
   date: 2026-11-20
   category: Рынки
   description: "Короткое описание для поиска и карточки"
   ---
   ```
   Текст ниже в Markdown. Строка `draft: true` скрывает статью.
3. Сохраните (commit) в ветку `main`. Сайт обновится через 1-2 минуты.

## Настройки
`site.config.json`: название, ссылки на Telegram, Threads, LinkedIn и форму рассылки. Пустые ссылки на сайте не показываются.

## Локально
```
npm install
npm run preview   # собрать вместе с черновиками
```
Результат в папке `dist/`.
